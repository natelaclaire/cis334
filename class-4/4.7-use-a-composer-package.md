# 4.7 Use a Composer package

Let's use an example from the textbook to demonstrate how to use one of the third-party libraries that we installed with Composer. We'll use the MathPHP library.

## Calculate the average

Create `public/tutorials/4-7-packages.php`:

```php
<?php
declare(strict_types=1);

use MathPHP\Statistics\Average;

require_once __DIR__ . '/../../vendor/autoload.php';

$numbers = [13, 18, 13, 14, 13, 16, 14, 21, 13];
$numbersString = implode(', ', $numbers);
$mean = Average::mean($numbers);
print "average of [$numbersString] = $mean";
```

Run:

```bash
php public/tutorials/4-7-packages.php
```
