# 4.10 Class 4 Discovery Project

Your discovery project for this week is to update your discovery project files, including the class files and the index file, to use namespaces and Composer's PSR-4 autoloading instead of explicit requires. Use the existing Composer configuration and bootstrap file. Your files are already in PSR-4-compliant locations, so you should not need to change any folders, filenames, or class names. Simply add appropriate `namespace` declarations to your classes, replace the explicit `require` statements with the Composer bootstrap in the index file, and use `use` statements to import the classes. Remember that the `App` namespace corresponds to the `src/` folder in your project, so since your class files are all below `src/Discovery`, the `App\Discovery` namespace will map to that directory.

As with all discovery projects, this is an opportunity for you to apply what you have learned in class and showcase your skills in PHP and object-oriented programming. Feel free to be creative, as long as you follow the requirements outlined above.
