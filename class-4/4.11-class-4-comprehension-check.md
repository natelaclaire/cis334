# 4.11 Class 4 comprehension check

Choose the best answer. Each question has exactly one correct answer.

## Questions

1. What does `use App\Models\User;` do?

   A. Downloads the User package.  
   B. Lets this file refer to that class as User without loading its file by itself.  
   C. Creates a User object.  
   D. Registers a directory with PHP.

2. Inside `namespace App\Services;`, what does `new DateTimeImmutable()` mean when there is no import for that name?

   A. Always the built-in class.  
   B. The first class found in src.  
   C. `App\Services\DateTimeImmutable`.  
   D. `App\DateTimeImmutable`.

3. Which statement about App is correct?

   A. It is a conventional namespace whose directory mapping must be configured.  
   B. It is a reserved PHP keyword.  
   C. It always means a directory named App.  
   D. It is available only after installing a framework.

4. During `composer init`, which type fits this application project?

   A. `composer-plugin`  
   B. `library`  
   C. `metapackage`  
   D. `project`

5. What does `spl_autoload_register($loader)` accomplish?

   A. Instantiates every class under src.  
   B. Registers a callback PHP can invoke when it needs an undeclared class.  
   C. Downloads Composer dependencies.  
   D. Automatically loads standalone functions whenever called.

6. Given the PSR-4 mapping `"App\\": "src/"`, where does `App\Services\WelcomeMessage` belong?

   A. `src/App/Services/WelcomeMessage.php`  
   B. `vendor/Services/WelcomeMessage.php`  
   C. `src/Services/WelcomeMessage.php`  
   D. `src/services/welcomemessage.php`, regardless of case.

7. You changed a namespace-prefix mapping in composer.json without changing dependencies. Which command regenerates the loader?

   A. `composer dump-autoload`  
   B. `composer init`  
   C. `php --version`  
   D. `composer hello`

8. A teammate clones an application with composer.json and composer.lock. Which command installs the locked dependency versions?

   A. `composer update`  
   B. `composer init`  
   C. `composer dump-autoload`  
   D. `composer install`

9. What does the constraint `^7.3` allow?

   A. Only 7.3.0.  
   B. Versions at least 7.3.0 and below 8.0.0.  
   C. Every version above 7.0.0, including 8.x.  
   D. Versions below 7.3.0.

10. What does the "global namespace" mean in PHP?

   A. The namespace containing PHP’s built-in functions and classes, along with code declared without a namespace
   B. A namespace whose contents are automatically shared between all PHP files
   C. A namespace used only for global variables declared with the global keyword
   D. The main namespace of an application, typically named App

## Answer key and teaching notes

1. **B.** An import selects a name in this file; loading is separate. Review 4.1.
2. **C.** Unimported class names resolve in the current namespace. Import the global class or use a leading backslash. Review 4.1.
3. **A.** App is a convention, not built-in directory discovery. Review 4.2.
4. **D.** Use project for this application; library describes reusable packages. Review 4.3.
5. **B.** The callback can load a class declaration on demand. Review 4.4.
6. **C.** Remove App, translate the remaining separators, and append .php under src. Case must match. Review 4.5.
7. **A.** Regenerate autoload metadata after changing the mapping. Review 4.5.
8. **D.** Install uses the existing lock; update resolves versions again. Review 4.6.
9. **B.** The caret allows compatible releases within this nonzero major version. Review 4.6.
10. **A.** Review 4.1.
