# 4.9 Class 4 reinforcement exercises

Complete these five exercises in order after tutorials 4.1–4.7. Use the same repository, PHP 8.4, and Composer 2. The tutorials provide all setup; no separate starter download is required. Use strict types, typed members, four-space indentation, and matching class filenames. Create `public/exercises/class4/` for your entry scripts. Its bootstrap path is `__DIR__ . '/../../../vendor/autoload.php'` because this folder is one level deeper than the tutorial entry folder.

## Exercise 4-1: Two classes, one short name

1. Create a `src/Exercises/Class4/Library/Book.php` declaring `App\Exercises\Class4\Library\Book`. Give it a constructor accepting a private string title and a `__toString(): string` method returning `Library: ` followed by the title.
2. Create `src/Exercises/Class4/Shop/Book.php` declaring `App\Exercises\Class4\Shop\Book` with the same constructor shape and a `__toString(): string` method returning `Shop: ` followed by the title.
3. Create `public/exercises/class4/index.php` with the Composer bootstrap. Import the two classes as `LibraryBook` and `ShopBook`. Construct one of each with title `PHP Practice` or another title and print both descriptions on separate lines.
4. Add a short written explanation of why two Book classes coexist and why use statements alone cannot load their files.

Expected output:

```text
Library: PHP Practice
Shop: PHP Practice
```

## Exercise 4-2: Using namespaces and inheritance together

Add an abstract class with the fully qualified name `App\Exercises\Class4\Shop\Item` in the proper location. Give it a constructor accepting a private string title and a private float price, a `__toString(): string` method returning `Shop Item: ` followed by the title and price, and public getters and setters for the price and title. Make `Shop\Book` extend this class and call the parent constructor and override the `__toString()` method with the previous text plus the price. Update `public/exercises/class4/index.php` to provide a price for the `ShopBook`, then confirm that the output looks the same as before plus the price.

## Exercise 4-3: Using the global namespace

Add an abstract class with the fully qualified name `App\Exercises\Class4\Library\Item` in the proper location. Give it a constructor accepting a private string title, a `__toString(): string` method returning `Item: ` followed by the title, and public getters and setters for the title. Add a line near the top of the file that reads `use DateTimeImmutable;` to create an alias for the global `DateTimeImmutable` class. Add a nullable property of type `DateTimeImmutable` called `$dateDue` with a `null` default value and a public getter for it. Create a public method called `setDueInDays(int $days): void` with the following body:

```php
// Note: the leading backslash is not needed if we import a global class with a use statement
$this->dateDue = (new DateTimeImmutable())->add(new \DateInterval("P{$days}D"));
```

Make `Library\Book` extend this class and call the parent constructor. Add the due date to the `__toString()` method's return value (hint: use `?->format('Y-m-d')` to get formatted output only if the date is not null). Update `public/exercises/class4/index.php` to call the `setDueInDays()` with a value of 7 method on the `Library\Book` instance and then confirm that the output includes the due date.

## Exercise 4-5: Get information about Composer libraries

1. Create `public/exercises/class4/composer-info.php` with the Composer bootstrap.
2. The Composer Runtime API provides `Composer\InstalledVersions` with static methods to query installed packages. Paste the following into the file to use `getInstalledPackages()` to print the names of all installed packages, one per line:

```php
<?php
declare(strict_types=1);
use Composer\InstalledVersions;
require_once __DIR__ . '/../../../vendor/autoload.php';

$packages = InstalledVersions::getInstalledPackages();
foreach ($packages as $package) {
    echo $package . " @ " . InstalledVersions::getPrettyVersion($package), '<br>', PHP_EOL;
}
```

3. Add an `if` block that uses the return value of `InstalledVersions::isInstalled('guzzlehttp/guzzle')` to print `Guzzle is installed` or `Guzzle is not installed`.
4. The `InstalledVersions::getRootPackage()` method returns an array of information about the root package (your own app project). Add code to print the root package's name and version:

```php
$rootInfo = InstalledVersions::getRootPackage();

echo "Project Name: " . $rootInfo['name'] . "<br>\n";
echo "Project Version: " . $rootInfo['pretty_version'] . "<br>\n";
```

5. Run the script and expect the list of packages followed by `Guzzle is installed` and the root package information.
