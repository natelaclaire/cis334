# 2.8 Dynamic Class Constant Fetch

> Supplemental topic: dynamic class constant fetch was added in PHP 8.3 and is not covered in *PHP Crash Course*.

Class constants hold fixed values associated with a class. Normally, the constant name is written directly:

```php
class MemberRole
{
    public const string STUDENT = 'student';
    public const string FACULTY = 'faculty';
    public const string STAFF = 'staff';
}

echo MemberRole::STUDENT;
```

Sometimes the constant name is determined at runtime. PHP 8.3 allows an expression between braces after `::`:

```php
$constantName = 'FACULTY';
echo MemberRole::{$constantName}; // faculty
```

The expression may be more than a variable:

```php
function roleConstantName(string $input): string
{
    return strtoupper(trim($input));
}

echo MemberRole::{roleConstantName('staff')}; // staff
```

## Validate dynamic names

A missing constant causes an `Error`. If the name comes from a request or another external source, validate it rather than assuming it exists:

```php
$requestedName = strtoupper((string) ($_GET['role'] ?? ''));
$qualifiedName = MemberRole::class . '::' . $requestedName;

if (!defined($qualifiedName)) {
    echo 'Unknown role.';
} else {
    echo MemberRole::{$requestedName};
}
```

Do not confuse a dynamic constant fetch with dynamic object properties:

```php
MemberRole::{$constantName}; // class constant selected at runtime
$member->{$propertyName};    // object property selected at runtime
```

## When to use it

Dynamic constant fetch is useful when a trusted configuration or mapping provides a constant name. If user input is meant to select among a small set of choices, an explicit `match` expression is often clearer and gives you a natural default case:

```php
$role = match ($input) {
    'student' => MemberRole::STUDENT,
    'faculty' => MemberRole::FACULTY,
    'staff' => MemberRole::STAFF,
    default => throw new InvalidArgumentException('Unknown role.'),
};
```

Choose the form that makes the allowed values easiest to see and verify.

See the PHP manual's [class constant documentation](https://www.php.net/manual/en/language.oop5.constants.php) for the complete syntax and visibility rules.
