# 2.7 Additional Magic Methods

> Supplemental topic: Chapters 17–18 introduce `__construct()` and `__toString()`. This tutorial surveys other magic methods that PHP invokes automatically in defined situations.

Magic methods begin with two underscores. Their names, visibility, parameters, and return types are part of PHP's language contract, so do not invent application methods beginning with `__`. Magic behavior is valuable when it expresses a familiar PHP operation, but it can obscure control flow when used unnecessarily.

## Serialization: `__serialize()` and `__unserialize()`

`serialize()` calls `__serialize()` to obtain the data that should be stored. `unserialize()` creates the object without calling its constructor and passes restored data to `__unserialize()`:

```php
class Product
{
    public function __construct(
        private string $name,
        private float $price,
    ) {
    }

    public function __serialize(): array
    {
        return ['name' => $this->name, 'price' => $this->price];
    }

    public function __unserialize(array $data): void
    {
        $this->name = (string) $data['name'];
        $this->price = (float) $data['price'];
    }
}

$stored = serialize(new Product('Notebook', 4.99));
$restored = unserialize($stored, ['allowed_classes' => [Product::class]]);
```

Never pass untrusted serialized data to `unserialize()`. Crafted input can instantiate classes and trigger application behavior. Prefer JSON for data interchange, and store server-controlled state in a session or database rather than a client-editable form field.

## Debug output: `__debugInfo()`

`var_dump()` uses `__debugInfo()` when it is present. Return useful diagnostic fields while omitting secrets:

```php
class Account
{
    public function __construct(
        private string $username,
        private string $passwordHash,
    ) {
    }

    public function __debugInfo(): array
    {
        return [
            'username' => $this->username,
            'passwordHash' => '[redacted]',
        ];
    }
}
```

Redacted debug output reduces accidental exposure, but it is not a substitute for controlling logs and error displays.

## Inaccessible properties: `__get()`, `__set()`, `__isset()`, and `__unset()`

These methods run when code interacts with an inaccessible or nonexistent property:

```php
class DataRecord
{
    /** @var array<string, mixed> */
    private array $data = [];

    public function __get(string $name): mixed
    {
        return $this->data[$name] ?? null;
    }

    public function __set(string $name, mixed $value): void
    {
        $this->data[$name] = $value;
    }

    public function __isset(string $name): bool
    {
        return isset($this->data[$name]);
    }

    public function __unset(string $name): void
    {
        unset($this->data[$name]);
    }
}
```

This pattern can wrap truly dynamic records, but ordinary typed properties or PHP 8.4 property hooks are clearer for a known schema. Misspelled property names can otherwise appear to work, reducing help from IDEs and static analysis.

## Inaccessible methods: `__call()` and `__callStatic()`

`__call()` receives the name and arguments for an inaccessible instance method. `__callStatic()` does the same for a static call:

```php
class Query
{
    public function __call(string $name, array $arguments): mixed
    {
        throw new BadMethodCallException("Unknown query method: {$name}");
    }

    public static function __callStatic(string $name, array $arguments): mixed
    {
        throw new BadMethodCallException("Unknown static query method: {$name}");
    }
}
```

Frameworks sometimes use these methods for fluent APIs or proxies. In application code, an explicitly declared method is usually easier to understand and type-check.

## Callable objects: `__invoke()`

An object with `__invoke()` can be called like a function while retaining configuration and state:

```php
class PriceWithTax
{
    public function __construct(private float $taxRate)
    {
    }

    public function __invoke(float $price): float
    {
        return $price * (1 + $this->taxRate);
    }
}

$addTax = new PriceWithTax(0.055);
echo $addTax(100.00); // 105.5
```

## Choosing explicit code or magic

| Need | Prefer |
|---|---|
| Initialize required state | `__construct()` |
| Provide a short string representation | `__toString()` |
| Make an independent copy | `clone` and, when needed, `__clone()` |
| Represent a known property with controlled access | typed property, methods, or property hooks |
| Wrap genuinely dynamic data | possibly `__get()` and related methods |
| Create a configured callable operation | `__invoke()` |

The [PHP magic-method reference](https://www.php.net/manual/en/language.oop5.magic.php) lists the required signatures and the additional magic methods not demonstrated here.
