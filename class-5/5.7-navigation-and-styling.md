# 5.7 Active navigation and shared styling

We will highlight the current page using blocks, then style the whole site by editing its base template. Keep the PHP files unchanged from 5.6.

## Add active-link blocks and local CSS

In `templates/tutorials/class5/base.html.twig`, replace the two navigation anchors with:

```twig
<a href="index.php?action=home" class="{% block homeLink %}{% endblock %}">Home</a>
<a href="index.php?action=contact" class="{% block contactLink %}{% endblock %}">Contact</a>
```

Add `{% block homeLink %}active{% endblock %}` after the title block in home.html.twig. Add `{% block contactLink %}active{% endblock %}` after the title block in contact.html.twig. Each page overrides only its own link block.

Add `<link rel="stylesheet" href="style.css">` inside the base template's head. Create `public/tutorials/class5/style.css`:

```css
body {
    font-family: sans-serif;
    max-width: 60rem;
    margin: 2rem auto;
    padding: 0 1rem;
}

header {
    background: #24364b;
    color: white;
    padding: 1rem;
}

nav a {
    color: #d0e2f5;
    margin-right: 1rem;
}

nav a.active {
    color: white;
    font-weight: bold;
    text-decoration: underline;
}
```

Visit both routes. Only the current link should be bold and underlined. View source and find class="active" on the correct anchor. The browser loads style.css relative to the entry-script URL, even though the markup came from templates outside public.

## Apply Bootstrap through the base template

The chapter finishes by replacing custom styling with Bootstrap. Replace all of `templates/tutorials/class5/base.html.twig` with this version; the children and controllers need no changes:

```twig
<!doctype html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Campus Club: {% block pageTitle %}Welcome{% endblock %}</title>
    <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css">
</head>
<body class="container py-4">
    <header class="navbar navbar-expand bg-dark px-3" data-bs-theme="dark">
        <span class="navbar-brand">Campus Club</span>
        <nav aria-label="Main navigation">
            <ul class="navbar-nav">
                <li class="nav-item">
                    <a href="index.php?action=home" class="nav-link {% block homeLink %}{% endblock %}">Home</a>
                </li>
                <li class="nav-item">
                    <a href="index.php?action=contact" class="nav-link {% block contactLink %}{% endblock %}">Contact</a>
                </li>
            </ul>
        </nav>
    </header>
    <section class="bg-light p-4 my-4 rounded">
        <p class="fs-4">Learn something together.</p>
        <p>Small projects. Shared discoveries.</p>
    </section>
    <h1>{{ block('pageTitle') }}</h1>
    <main>
        {% block main %}{% endblock %}
    </main>
</body>
</html>
```

This uses a pinned Bootstrap 5.3 release, updating the chapter's 5.1 example. The old stylesheet can remain for comparison, but it is no longer linked. Internet access is needed for the CDN stylesheet; if unavailable, retain the local-CSS version for the demonstration. No Bootstrap JavaScript is needed for this always-visible navigation.

## Final checkpoint

Open Home and Contact and resize the browser. Verify titles, distinct page content, shared spacing and header, and exactly one active navigation link on each page. The child contributes active alongside the base template's nav-link class. No PHP branch chooses a CSS class.

Reference: [Bootstrap getting started](https://getbootstrap.com/docs/5.3/getting-started/introduction/).
