# 5.11 Class 5 comprehension check

Choose the best answer. Each question has exactly one correct answer.

## Questions

1. What is Twig's main responsibility in these examples?

   A. Install PHP classes.  
   B. Choose the action query parameter.  
   C. Render a view using a template and provided data.  
   D. Store staff records in a database.  

2. What does FilesystemLoader receive in our Application constructor?

   A. The filesystem directory containing the templates.  
   B. The URL of the current page.  
   C. The namespace of the Product class.  
   D. The text of the final HTML response.  

3. Given `$args = ['name' => 'Avery'];`, which expression outputs that value in Twig?

   A. `<?= $name ?>`  
   B. `{% name %}`  
   C. `{{ $name }}`  
   D. `{{ name }}`  

4. What does `$this->twig->render('home.html.twig', $args)` return?

   A. An Application object.  
   B. A string containing rendered output.  
   C. A newly installed Composer package.  
   D. The template directory.  

5. Product has a private price and a public getPrice(). What does `{{ product.price }}` do?

   A. Changes price to public.  
   B. Always throws an error because price is private.  
   C. Uses the public getter to obtain the price.  
   D. Prints the source code of getPrice().  

6. Which Twig construct repeats a table row for each Staff object?

   A. `{% for person in staff %} ... {% endfor %}`  
   B. `{{ foreach ($staff as $person) }}`  
   C. `{% extends staff %}`  
   D. `{{ block('staff') }}`  

7. In our two-page application, what happens for an unknown action?

   A. Twig creates a new template.  
   B. The query text becomes a template filename.  
   C. Composer searches for another controller.  
   D. The switch selects the Home method through its default branch.  

8. What does `{{ include('_header.html.twig') }}` do?

   A. Makes the caller a PHP subclass.  
   B. Renders the partial at that location using the current context by default.  
   C. Redirects the browser to the partial.  
   D. Registers a new Composer autoload rule.  

9. Why use `{{ block('pageTitle') }}` in the h1 after declaring pageTitle in the title element?

   A. To create a context variable named pageTitle.  
   B. To prevent children from overriding the title.  
   C. To render the effective block again without declaring it twice.  
   D. To load a PHP class named pageTitle.  

10. How does the Contact child highlight only its own navigation link?

   A. It overrides contactLink with active; base places that block inside the link class attribute.  
   B. It rewrites the shared CSS file on each request.  
   C. It passes its template filename to Composer.  
   D. It puts active in every link block.  

## Answer key and teaching notes

1. **C.** Twig renders the view; PHP prepares data and selects a response. Review 5.1.
2. **A.** The loader searches its configured template directory. Review 5.1.
3. **D.** Output uses double braces and the context key without a dollar sign. Review 5.1.
4. **B.** Our code then echoes the returned string. Review 5.1.
5. **C.** Dot notation can resolve through a public getter; private visibility remains intact. Review 5.2.
6. **A.** The for tag repeats template content for a sequence. Review 5.2.
7. **D.** The controller explicitly defines this fallback. Review 5.3.
8. **B.** Includes insert rendered template content. Review 5.4.
9. **C.** The child can override one block whose content is reused in two locations. Review 5.6.
10. **A.** Named blocks let each child contribute a class to its corresponding link. Review 5.7.
