# 5.5 Template inheritance

Template inheritance puts the shared document in a base template. Child templates select that base and override named regions. This resembles PHP inheritance, but the declarations here belong to Twig templates, not PHP classes.

## Create a complete base

Create `templates/tutorials/class5/base.html.twig`:

```twig
<!doctype html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <title>Campus Club: {{ pageTitle }}</title>
</head>
<body>
    <header>
        <p>Campus Club</p>
        <nav aria-label="Main navigation">
            <a href="index.php?action=home">Home</a>
            <a href="index.php?action=contact">Contact</a>
        </nav>
    </header>
    <h1>{{ pageTitle }}</h1>
    <main>
        {% block main %}{% endblock %}
    </main>
</body>
</html>
```

The main block is empty by default. Its location determines where a child's content will appear. The HTML main element and the Twig block happen to share a name; they are different constructs.

Replace `templates/tutorials/class5/home.html.twig` with:

```twig
{% extends 'base.html.twig' %}

{% block main %}
    <p>Explore a new skill with classmates each week.</p>
{% endblock %}
```

Replace `templates/tutorials/class5/contact.html.twig` with:

```twig
{% extends 'base.html.twig' %}

{% block main %}
    <p>Contact the club organizers.</p>
    <dl>
        <dt>Email</dt>
        <dd>club@example.com</dd>
        <dt>Meeting room</dt>
        <dd>Library 204</dd>
    </dl>
{% endblock %}
```

Keep Application unchanged: it still renders the child template and passes pageTitle. Twig finds the parent through extends and uses the child's main block. Put extends first and keep page-specific output inside blocks. Do not also include the old header; that would duplicate document markup. The earlier _header file may remain for comparison, but neither current page uses it.

## Verify and discuss

Both pages should still show their original content. Add `<footer>Campus Club learning series</footer>` immediately after `</main>` in base.html.twig. Confirm the footer appears on both pages. Check that the response contains just one html and body element.

Which template does PHP render, and which file owns the document? PHP renders home or contact; base owns the shared layout. A child may leave a block at its default. Misspelling main in the child will not override the parent's main block.

Reference: [Twig extends and inheritance](https://twig.symfony.com/doc/3.x/tags/extends.html).
