# 5.0 Class 5 overview and tutorial roadmap

Class 5 covers Chapter 21, **Efficient Template Design with Twig**, in *PHP Crash Course*. This is our first Twig lesson. We build one cumulative Campus Club website, starting with a greeting and ending with two pages that share a layout. All examples are new for this week.

By the end of class, you should be able to trace a request through an Application object, pass data to Twig, read arrays and objects in templates, route between pages, and use includes, inheritance, blocks, and shared styles to reduce duplication.

## Instructor preparation

Use the existing student repository, PHP 8.4, and Composer setup from last week. Twig is already installed. Keep the existing composer.json, composer.lock, dependencies, and `"App\\": "src/"` PSR-4 mapping. Do not run composer init, reinstall Twig, or copy vendor from another project. If a freshly cloned repository lacks vendor, restore its locked dependencies with `composer install` as a preparation step.

Every path in these tutorials refers to the **student repository root**, not this course-notes folder. Create folders with the editor as needed. PHP files use strict types and omit the closing PHP tag. Tutorials 5.1–5.7 update the same entry script and Application class; follow replacements in order. No other week's files are moved or reused.

```text
composer.json                         (existing)
composer.lock                         (existing)
vendor/autoload.php                   (existing)
public/
    tutorials/class5/index.php
    tutorials/class5/style.css        (introduced in 5.7)
    exercises/class5/index.php
src/
    Tutorials/Class5/Application.php
    Tutorials/Class5/Product.php
    Exercises/Class5/Application.php
    Exercises/Class5/Staff.php
templates/
    tutorials/class5/                 (hello, demo, home, contact, base, _header)
    exercises/class5/                 (separate exercise templates)
```

Templates stay outside the public document root. Start the local server from the student repository root:

```bash
php -S localhost:8000 -t public
```

Visit `http://localhost:8000/tutorials/class5/index.php`. With an existing hosted course environment, use its corresponding `/tutorials/class5/index.php` URL instead. Use browser requests to test query parameters; running the file at the CLI does not supply URL parameters. Relative navigation such as `index.php?action=contact` keeps the browser inside this week's folder.

## Chapter alignment and teaching notes

The chapter's simple example maps to 5.1, its objects/arrays section to 5.2, the multipage Application to 5.3, include to 5.4, inheritance to 5.5, blocks instead of variables to 5.6, and both CSS stages to 5.7. The chapter's final exercise asks for a staff table with a Twig loop; 5.2 supplies that prerequisite explicitly. Basic HTML escaping, strict-variable diagnostics, and handling a non-string action are small instructional supplements.

Use the textbook's progression, but retain our existing App namespace and nested paths. The greeting and data-demo templates remain as earlier learning artifacts after routing is introduced. The header partial remains after inheritance replaces its use. No discovery project or migration work is part of this update.

Instructor prompt: “What stays in PHP, and what belongs in the view?” PHP selects a response and prepares data; Twig describes how that data appears. Twig does not make every template or application automatically safe. Our examples use trusted templates and HTML autoescaping; they do not execute submitted template text.

Source: supplied EPUB, `OEBPS/xhtml/chapter21.xhtml`. Examples adapt its concepts with original names and content. See [instructor validation notes](class-5-instructor-notes.md) for checks and common troubleshooting points.
