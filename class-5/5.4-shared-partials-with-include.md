# 5.4 Shared partials with include

A partial contains markup shared by several templates. We will move the duplicated opening HTML into one file and render it from each page. Keep Application and index unchanged from 5.3.

## Extract the header

Create `templates/tutorials/class5/_header.html.twig`:

```twig
<!doctype html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <title>Campus Club: {{ pageTitle }}</title>
</head>
<body>
    <header>
        <p>Campus Club</p>
        <nav aria-label="Main navigation">
            <a href="index.php?action=home">Home</a>
            <a href="index.php?action=contact">Contact</a>
        </nav>
    </header>
    <h1>{{ pageTitle }}</h1>
```

The underscore is a naming convention, not special Twig syntax. This partial intentionally opens the document; its callers still close it.

Replace `templates/tutorials/class5/home.html.twig` with:

```twig
{{ include('_header.html.twig') }}
    <p>Explore a new skill with classmates each week.</p>
</body>
</html>
```

Replace `templates/tutorials/class5/contact.html.twig` with:

```twig
{{ include('_header.html.twig') }}
    <p>Contact the club organizers.</p>
    <dl>
        <dt>Email</dt>
        <dd>club@example.com</dd>
        <dt>Meeting room</dt>
        <dd>Library 204</dd>
    </dl>
</body>
</html>
```

The include function renders the partial at that location. It receives the current context by default, including pageTitle. The path is relative to our template loader, not to the browser URL. No PHP require belongs in these Twig files.

## Verify and discuss

Reload both routes: their appearance should be unchanged. Temporarily change “Campus Club” in the header paragraph to “Campus Learning Club”; both pages should change. Restore the text. View source and confirm one doctype and one closing html tag per response.

We could extract closing tags into a footer partial, but that still spreads the document structure across files. Next we give one base template responsibility for the whole structure. Includes remain useful within inheritance for reusable pieces, such as a contact card used by a few pages.

Reference: [Twig include function](https://twig.symfony.com/doc/3.x/functions/include.html).
