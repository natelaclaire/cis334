# 5.9 Class 5 reinforcement exercises

Complete these five exercises in order after tutorials 5.1–5.7. Build a separate cumulative **Campus Help Desk** site in the same student repository. Reuse the existing Composer setup and installed Twig. All five exercises use `public/exercises/class5/index.php`; put classes in `src/Exercises/Class5/` with namespace `App\Exercises\Class5`, and templates in `templates/exercises/class5/`.

Use strict types, typed members and returns, matching filenames, and four-space indentation. The entry script's Composer path is `__DIR__ . '/../../../vendor/autoload.php'`. The exercise Application's template directory is `__DIR__ . '/../../../templates/exercises/class5'`. Use the existing server with `/exercises/class5/index.php`.

## Exercise 5-1: Getting started with Twig

1. Create `src/Exercises/Class5/Application.php` with the following content:

```php
<?php
declare(strict_types=1);

namespace App\Exercises\Class5;

use Twig\Environment;
use Twig\Loader\FilesystemLoader;

class Application
{
    private const PATH_TO_TEMPLATES = __DIR__ . '/../../../templates/exercises/class5';

    private Environment $twig;

    public function __construct()
    {
        $loader = new FilesystemLoader(self::PATH_TO_TEMPLATES);
        $this->twig = new Environment($loader, [
            'autoescape' => 'html',
            'strict_variables' => true,
        ]);
    }

    public function run()
    {
        // TODO: read $_GET['action'] and call home()
    }

    // TODO: implement home() method
}
```

2. Complete the run() method to read `$_GET['action']` and call home() for the default case or 'home'. Missing, unknown, or non-string actions should select home().
3. Implement home() to render `home.html.twig`.
4. Create `public/exercises/class5/index.php` to instantiate and run the Application:

```php
<?php
declare(strict_types=1);

use App\Exercises\Class5\Application;

require_once __DIR__ . '/../../../vendor/autoload.php';

$app = new Application();
$app->run();
```

5. Create `templates/exercises/class5/home.html.twig` with an HTML page and a simple greeting.

Check: page should show the simple greeting.

## Exercise 5-2: Template inheritance

1. Create `base.html.twig` with the entire document structure, a pageTitle block, a repeated title via block('pageTitle'), and a main block as we did in the tutorials.
2. Make `home.html.twig` extend base and override pageTitle and main.

Check: the browser tab shows the child title, the h1 shows the same title, and the greeting appears in main. The response contains just one html and body element. Essentially, nothing changed visually, but the child template now inherits the shared layout from base.

## Exercise 5-3: Display objects and an array

1. Create `src/Exercises/Class5/Staff.php` with private string name and jobTitle properties, a constructor initializing both, and public getName() and getJobTitle() methods.
2. In the `Application` class, create a new method called `staff()` that creates three Staff objects: Avery / Tutor, Morgan / Lab assistant, and Riley / Coordinator.
2. Pass the staff array to a new child template `staff.html.twig` with pageTitle = Staff. The template should display the staff members in a table with Name and Job title headings.
3. Add a case for 'staff' in run() to call the staff() method. Add a navigation link to the Staff page (`/exercises/class5/index.php?action=staff`) in the `base.html.twig` template.

Check: three data rows with the correct names and job titles appear. Do not build the table HTML inside Staff or Application.

## Exercise 5-4: Add a personalized greeting form

1. Add a property to the Application class for `$name`.
2. In the constructor, populate the property from `$_SESSION['name']` or default to Visitor.
3. Add the following form to the base template:

```twig
<form method="post" action="index.php?action=name">
    <label for="name">Your name:</label>
    <input type="text" id="name" name="name" value="{{ name }}">
    <button type="submit">Update</button>
</form>
```

4. Add a `name()` method to the Application class. In the `name()` method, read `$_POST['name']` and store it in `$_SESSION['name']` if it is a non-empty string. Redirect to the home page to avoid resubmission.
5. Add a case for 'name' in run() to call the name() method only if the request is a POST request.
6. Pass the `$name` property to each child template.
7. Add `session_start();` to the entry script (index.php) before the Application is instantiated.

Check: before submitting the form, the greeting should show Visitor. After submitting a non-empty name, the greeting should show that name regardless of which page you are on. Submitting an empty string should not change the greeting.

## Exercise 5-5: Twig functions

1. Explore the [Twig functions](https://twig.symfony.com/doc/3.x/functions/index.html) and [filters](https://twig.symfony.com/doc/3.x/filters/index.html). Use at least three different functions and/or filters in your templates (beyond the ones already used). For example, you could use `date()` to show the current date, `upper()` to display the name in uppercase, and `random()` to show random values.
2. When submitting the assignment, please explain which functions and filters you used and where in your templates.
