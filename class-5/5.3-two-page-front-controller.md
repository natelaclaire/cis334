# 5.3 A two-page front controller

We now turn the same application into a two-page site. A query parameter chooses which controller method runs. Both pages initially repeat HTML so we can see what the next refactoring removes. Keep the entry script unchanged.

## Replace the Application class

Replace `src/Tutorials/Class5/Application.php` with:

```php
<?php
declare(strict_types=1);

namespace App\Tutorials\Class5;

use Twig\Environment;
use Twig\Loader\FilesystemLoader;

class Application
{
    private const PATH_TO_TEMPLATES = __DIR__ . '/../../../templates/tutorials/class5';

    private Environment $twig;

    public function __construct()
    {
        $loader = new FilesystemLoader(self::PATH_TO_TEMPLATES);
        $this->twig = new Environment($loader, [
            'autoescape' => 'html',
            'strict_variables' => true,
        ]);
    }

    public function run(): void
    {
        $action = $_GET['action'] ?? 'home';
        if (!is_string($action)) {
            $action = 'home';
        }

        switch ($action) {
            case 'contact':
                $this->contact();
                break;
            case 'home':
            default:
                $this->home();
        }
    }

    private function home(): void
    {
        $template = 'home.html.twig';
        $args = ['pageTitle' => 'Home'];
        echo $this->twig->render($template, $args);
    }

    private function contact(): void
    {
        $template = 'contact.html.twig';
        $args = ['pageTitle' => 'Contact'];
        echo $this->twig->render($template, $args);
    }
}
```

The `run()` method acts as the front controller. The null-coalescing operator supplies a default when action is absent. The string check handles an array-shaped query such as `?action[]=contact`. The switch selects known methods; it never uses user input as a template filename. Like the chapter, unknown actions fall back to Home. A later application might deliberately return a 404 instead.

## Add two templates

Create `templates/tutorials/class5/home.html.twig`:

```twig
<!doctype html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <title>Campus Club: {{ pageTitle }}</title>
</head>
<body>
    <header>
        <p>Campus Club</p>
        <nav aria-label="Main navigation">
            <a href="index.php?action=home">Home</a>
            <a href="index.php?action=contact">Contact</a>
        </nav>
    </header>
    <h1>{{ pageTitle }}</h1>
    <p>Explore a new skill with classmates each week.</p>
</body>
</html>
```

Create `templates/tutorials/class5/contact.html.twig`:

```twig
<!doctype html>
<html lang="en">
<head>
    <meta charset="utf-8">
    <title>Campus Club: {{ pageTitle }}</title>
</head>
<body>
    <header>
        <p>Campus Club</p>
        <nav aria-label="Main navigation">
            <a href="index.php?action=home">Home</a>
            <a href="index.php?action=contact">Contact</a>
        </nav>
    </header>
    <h1>{{ pageTitle }}</h1>
    <p>Contact the club organizers.</p>
    <dl>
        <dt>Email</dt>
        <dd>club@example.com</dd>
        <dt>Meeting room</dt>
        <dd>Library 204</dd>
    </dl>
</body>
</html>
```

## Verify the routes

Open `/tutorials/class5/index.php`, then follow Contact and Home. Expect different titles, headings, and main content with identical navigation. Try `?action=unknown` and `?action[]=contact`; both should show Home. The old hello and demo templates stay in the project, but this version of run no longer renders them.
