# 6.10 Class 6 Discovery Project

Your discovery project for this week is to update your discovery project site to use Twig templates. You will need to create a base template and one child template for the home page (our only current page). The base template should contain the shared layout and navigation, while the "home" child template should contain the unique content for the home page. I'll leave it up to you to determine what portions of the current home page are going to be shared and what is unique to the home page. Place the templates in a new folder called `templates/discovery`.

Use the Application class from our tutorials as a guide to create a new Application class for the discovery projects under the `App\Discovery` namespace. Your new Application class should be located in `src/Discovery/Application.php`. You will need to update the `public/discovery/index.php` entry script to use the new Application class instead of the current code that renders the HTML directly. Your arrays in your `index.php` will most likely need to be moved to the new Application class as well, so that they can be passed to the Twig templates for rendering. Remember, these arrays will eventually be replaced with database queries.

Additionally, currently we are following a poor practice of having our `Post` and `ImagePost` classes render their own HTML. This is not a good practice because it mixes the data and logic of our application with the presentation of our application. For this discovery project, you will need to update the `Post` and `ImagePost` classes to use Twig templates for rendering their HTML instead of rendering it directly in the class. You will need to create a new partial template for each class that contains the HTML for rendering the post or image post. The templates should be placed in the `templates/discovery` folder. Instead of calling the `render()` method on the `Post` and `ImagePost` classes, your home template will include the proper partial template for each post type as it iterates through the posts. Note that the include() function provides a second parameter available to pass additional context to the included template. For example, you might set it up like this in your `templates/discovery/home.html.twig` template:

```twig
{% extends 'base.html.twig' %}

{% block main %}
    {% for post in posts %}
        {{ include('_' ~ post.type ~ '.html.twig', { post: post }) }}
    {% endfor %}
{% endblock %}
```

*In order for the above to work, you will need to add a `getType()` method to the `Post` and `ImagePost` classes that returns a string indicating the type of post. For example, the `Post` class might return "post" and the `ImagePost` class might return "image_post" in order to match the template names of `_post.html.twig` and `_image_post.html.twig` respectively. This will allow you to dynamically include the proper partial template for each post type.*

As with all discovery projects, this is an opportunity for you to apply what you have learned in class and showcase your skills in PHP and object-oriented programming. It's also an opportunity for you to explore and discover. Feel free to be creative, as long as you follow the requirements outlined above.
