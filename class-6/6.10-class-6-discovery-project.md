# 6.10 Class 6 Discovery Project

As you've probably guessed, your discovery project for this week is to split your controller logic into separate front and display controllers. The front controller will read the action parameter and delegate to the appropriate display controller, which will render the page. For the display controller, we only need one at the moment. Although we are currently calling the existing page a home page, it's really more of a feed, so I recommend calling the display controller a FeedController. Create three actions for the feed: the current default feed as one action, an action that displays only text posts (`Post` objects), and an action that displays only image posts (`ImagePost` objects). Add buttons or links to the feed page that allow the user to select which feed they want to see. The default feed should show all posts, while the other two actions should filter the posts accordingly. You will need to update your Twig templates to accommodate these changes as well. Use a single array of posts that contains both `Post` and `ImagePost` objects stored as a property of the FeedController, and filter them in the display controller based on the action selected.

In case you get stuck determining how to filter the posts, check out the [PHP get_class() function](https://www.php.net/manual/en/function.get-class.php) and the [PHP instanceof operator](https://www.php.net/manual/en/language.operators.type.php). You can use either of these to determine the type of each post in your feed and filter them accordingly, but there are nuances to consider when using each approach and there are other approaches as well.

As with all discovery projects, this is an opportunity for you to apply what you have learned in class and showcase your skills in PHP and object-oriented programming. It's also an opportunity for you to explore and discover. Feel free to be creative, as long as you follow the requirements outlined above.
