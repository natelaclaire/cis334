# 6.0 Class 6 overview and tutorial roadmap

Class 6 covers Chapter 22, **Structuring an Object-Oriented Web Application**, in *PHP Crash Course*. This is our first lesson on separating display logic into page-controller classes while keeping request decisions in a front controller. We build a new cumulative **Campus Supply** site. No archived scripts or files from other weeks need to be moved or copied.

By the end of class, you should be able to trace a request, distinguish a front controller from a page controller, add a specialized controller and view, and use an abstract superclass with a protected Twig property to remove repeated setup.

## Instructor preparation

Use the existing student repository and **PHP 8.4 or newer** for both CLI and web requests; the property hooks in 6.3 require it. Check the selected runtime with `php -v`. Keep composer.json, composer.lock, the existing `"App\\": "src/"` PSR-4 mapping, and pre-installed Twig. Do not run composer init, add another autoload mapping, or reinstall Twig. For a fresh clone that has no vendor directory, restore the locked dependencies with `composer install` before class.

Every path in these tutorials is relative to the **student repository root**, not this course-notes folder. Create new files in this week's folders. Tutorials are cumulative; a replacement means replace that whole file. PHP files use strict types, typed members and returns, and no closing PHP tag.

```text
composer.json                              (existing)
composer.lock                              (existing)
vendor/autoload.php                        (existing)
public/
    tutorials/class6/index.php
    tutorials/class6/style.css
    exercises/class6/index.php
src/
    Tutorials/Class6/
        Application.php
        DefaultController.php
        Product.php
        ProductController.php
        Controller.php
    Exercises/Class6/
        Application.php
        DefaultController.php
        Staff.php
        StaffController.php
        Controller.php
templates/
    tutorials/class6/                      (base, home, contact, products, product, product-not-found)
    exercises/class6/                      (base, home, contact, privacy, staff)
```

Templates stay outside the public document root. Start the server from the student repository root:

```bash
php -S localhost:8000 -t public
```

Open `http://localhost:8000/tutorials/class6/index.php`. Exercises use `http://localhost:8000/exercises/class6/index.php`. In a hosted environment, use its corresponding nested URLs. Navigate with relative `index.php?action=...` links so requests stay inside this week's folder. Test query strings in a browser; a plain CLI execution does not populate GET parameters.

## Chapter alignment and teaching notes

Tutorial 6.1 supplies a fresh starting point so students do not depend on earlier files. Tutorial 6.2 covers “Separating Display and Front-Controller Logic” (listings 22-1–22-2). Tutorials 6.3–6.4 cover “Using Multiple Controller Classes” (22-3–22-7), with property hooks added as a course extension. Tutorial 6.5 covers “Sharing Controller Features Through Inheritance” (22-8–22-10). Tutorial 6.6 extends the architecture with a single-product route and an explicit parent-constructor call; 6.7 consolidates the complete request flow. Exercises 6-3 and 6-4 adapt the chapter's privacy and staff tasks; the remaining exercises reinforce separation and inheritance.

Preserve the chapter's simple architecture: hard-coded sample data, explicit switch routing, and page controllers that render Twig views. Databases, login systems, framework routers, and dependency-injection containers are outside this lesson. Non-string action handling, explicit HTML autoescaping, strict-variable diagnostics, and a local stylesheet are small course adaptations.

Instructor prompt: “Which class decides what happens, which class prepares the page, and which file defines the HTML?” The answer is Application, the selected page controller, and the Twig template, respectively.

Source: supplied EPUB, `OEBPS/xhtml/chapter22.xhtml`, pp. 427–439. Examples use original names and content while following the chapter's progression. See [instructor notes](class-6-instructor-notes.md) for checkpoints and textbook corrections.
