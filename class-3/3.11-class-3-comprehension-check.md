# 3.11 Class 3 comprehension check

Choose the best answer for each question. Each question has one correct answer.

## Questions

1. Given `class SailBoat extends Boat` and `class Boat extends Vehicle`, which statement is correct?

   A. SailBoat has two direct parents.  
   B. SailBoat can use accessible members inherited through Boat from Vehicle.  
   C. PHP forbids more than one level of inheritance.  
   D. SailBoat must also declare `extends Vehicle`.

2. A property is declared protected in Vehicle. Which code can directly access it?

   A. Only code outside Vehicle.  
   B. Any code that has a Vehicle object.  
   C. Only a static method.  
   D. Methods in Vehicle and its subclasses, within the inheritance access rules.

3. What does declaring a class abstract guarantee?

   A. Every method in it has no body.  
   B. It cannot have a constructor.  
   C. It cannot be instantiated directly.  
   D. Its subclasses cannot be instantiated.

4. `show(Food $food)` calls `$food->describe()`. A Dessert subclass overrides `describe()`. What happens when a Dessert is passed?

   A. Dessert's implementation runs.  
   B. Food's implementation must run because of the parameter type.  
   C. Both implementations always run.  
   D. PHP rejects the object because it is not exactly Food.

5. A parent declares `label(): string`. Which child declaration is compatible?

   A. `label(string $prefix): string`  
   B. `label(): int`  
   C. `label(string $prefix = ''): string`  
   D. `label(): array`

6. What is a native PHP attribute?

   A. Any private property.  
   B. Structured metadata attached to a declaration with `#[...]`.  
   C. A replacement for every method body.  
   D. A database foreign key.

7. On PHP 8.4, what happens when `#[Override]` marks a child method named `descrbie()`, but the parent only has `describe()` and there is no other matching inherited method?

   A. PHP automatically corrects the name.  
   B. PHP calls both methods.  
   C. The attribute is only a comment.  
   D. PHP emits a compile-time error.

8. A child overrides `make(string $text): string` to trim input before the parent formats it. What is the appropriate order?

   A. Trim `$text`, call `parent::make($text)`, then use or return its result.  
   B. Call the parent, trim `$text`, and assume the previous result changes.  
   C. Call `$this->make($text)` from the override instead of the parent.  
   D. Add Override and let it call the parent automatically.

9. Which statement correctly describes `final`?

   A. A final method cannot be called.  
   B. A final class is automatically immutable.  
   C. A final method cannot be overridden; a final class cannot be extended.  
   D. A final method must have no body.

10. Players can record multiple scores for the same game. Each score has exactly one player and game. Which ERD design fits?

   A. Score has only a game ID; players are inferred from points.  
   B. Score has its own primary key plus player and game foreign keys; the player/game pair may repeat.  
   C. The player/game pair must be unique in Score.  
   D. Score inherits from Player instead of referencing it.

## Answer key and teaching notes

1. **B.** A class has one direct parent, but inheritance can span multiple levels. Review 3.1.
2. **D.** Protected supports access inside the hierarchy without exposing the member publicly. Review 3.2.
3. **C.** Abstract prevents direct instantiation; it may contain implemented methods and a constructor. Review 3.2.
4. **A.** The actual object determines which override runs. Review 3.3.
5. **C.** An added optional argument preserves calls without arguments. Review 3.3.
6. **B.** Attributes supply metadata; a consumer determines its effect. Review 3.4.
7. **D.** Override checks the declared intent and reveals the typo. Review 3.4.
8. **A.** Preparation must happen before the operation that consumes the prepared value. Review 3.5.
9. **C.** These restrictions control extension, not whether methods can execute or state can change. Review 3.6.
10. **B.** The separate score ID permits repeated attempts; foreign keys connect each attempt to its parents. Review 3.7.

Suggested scoring: 9–10 ready to continue; 7–8 review missed tutorial sections; 0–6 revisit the demonstrations and exercises. Keep the answer key out of the student-facing quiz when importing questions into the LMS.
