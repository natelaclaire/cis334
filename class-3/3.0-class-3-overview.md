# 3.0 Class 3 overview and tutorial roadmap

Class 3 covers Chapter 19, **Inheritance**, in *PHP Crash Course*. We build on Class 2's classes and objects using PHP 8.4. Attributes and the Override attribute are modern PHP supplements; the ERD video prepares you for an upcoming assignment and is not Chapter 19 material.

By the end of class, you should be able to:

* identify a useful superclass and build single and multilevel inheritance;
* explain public, protected, and private access in a class hierarchy;
* distinguish an abstract class from a concrete class;
* override methods while preserving the parent's contract;
* use `#[Override]` to check your intent;
* decide whether and when an override should call its parent;
* distinguish final classes from final methods; and
* read and draw a basic ERD with keys, cardinality, and an associative entity.

## Instructor preparation

Use separate scratch files for the full examples in each tutorial. Run them from the terminal with PHP 8.4; HTML escaping is unnecessary for these CLI examples. Snippets explicitly labeled as replacements belong inside the indicated class. Run intentional failures separately and restore the working example before continuing.

Chapter 19 uses Vehicle/Car/Boat, Food/Dessert, and Product examples. These notes use original, simplified demonstrations with the same concepts. Abstract **methods** and `instanceof` are brief supporting extensions; Chapter 19 focuses on abstract **classes**. Interfaces, traits, namespaces, autoloading, and database implementation are outside this class's required scope.
