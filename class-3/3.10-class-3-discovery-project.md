# 3.10 Class 3 Discovery Project

Your discovery project for this week is to extend the Campus Connect application by using inheritance.

Create a subclass of `Post` called `ImagePost`. This subclass should have additional properties for the image URL and image alt text, and override the `render()` method to include the image in the output. It should use the `#[Override]` attribute to indicate that the `render()` method is overriding the parent method. Consider how you might update the `Post::render()` method so that the `ImagePost::render()` method can augment instead of replacing it. The HTML output from the `ImagePost::render()` method should be nearly identical to the `Post::render()` method, except that it should output an image tag with the image URL and alt text as the first element inside the `article` element using Bootstrap's `card-img-top` class:

```html
<img src="..." class="card-img-top" alt="...">
```

The `ImagePost` class should also have a constructor that accepts a `Member` object, a string for the post date, a string for the post body, a string for the image URL, and a string for the image alt text. The constructor should call the parent constructor using the `parent::__construct()` syntax to initialize the parent class properties.

Then create subclasses of `Member` called `StudentMember` and `FacultyMember`. These subclasses should have additional properties specific to students and faculty - you choose what those properties are (at least one additional property per type). For example, `StudentMember` could have a property for the student's major, while `FacultyMember` could have a property for the faculty member's department. Each subclass should have a constructor that accepts the appropriate parameters and calls the parent constructor using the `parent::__construct()` syntax to initialize the parent class properties. Make `Member` an abstract class so that it cannot be instantiated directly. Include a method in each subclass that returns a string representation of the member's name, member type (e.g., "Student" or "Faculty"), and at least one additional property specific to that member type, and use that in the `render()` method instead of showing just the name.

In your `public/discovery/index.php` file, create instances of `ImagePost` and add them to the `$posts` array. For the images, feel free to use your own images, find some online (e.g., from Unsplash or Pexels), or use placeholder images from <https://placehold.co/>. Then change all instances of `Member` to instances of `StudentMember` and `FacultyMember` when instantiating the posts since `Member` is now an abstract class.

As with all discovery projects, this is an opportunity for you to apply what you have learned in class and showcase your skills in PHP and object-oriented programming. Feel free to be creative, as long as you follow the requirements outlined above.
