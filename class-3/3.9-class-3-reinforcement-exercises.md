# 3.9 Class 3 reinforcement exercises

Complete these five exercises in order. You will build a small catalog of library media, then model its loans. Use PHP 8.4, strict types, typed members, and four-space indentation. These are terminal exercises; no browser, database, namespace, autoloader, or preexisting starter files are required.

Class files will be placed in `src/Exercises/Class3/` and the entry script in `public/class3/`. The entry script should load each class explicitly with `require_once`.

Put `<?php` and `declare(strict_types=1);` at the top of every PHP file. Do not add closing PHP tags. Each class belongs in its matching file.

## Exercise 3-1: Generalize shared state

Books and DVDs both have a title and a positive catalog ID. Create an **abstract** `MediaItem` superclass. Use this starting body in `MediaItem.php`, then replace the TODO comments:

```php
abstract class MediaItem
{
    private int $id;

    public function __construct(int $id, protected string $title)
    {
        // TODO: initialize the ID through setId().
    }

    public function setId(int $id): void
    {
        // TODO: reject IDs <= 0 with InvalidArgumentException,
        // then assign the valid ID to the private property.
    }

    public function getId(): int
    {
        // TODO: return the ID.
    }

    public function describe(): string
    {
        // TODO: return 'Media: ' followed by the title.
    }
}
```

1. Finish the methods. No method is abstract; the class itself is abstract because this catalog requires a specific kind of media item. For an example of how to accomplish the TODO in `setId()`, see the `Game` class in Class 2's reinforcement exercises.
2. Add empty `Book extends MediaItem` and `DVD extends MediaItem` declarations in their matching files.

Open `/exercises/class3/index.php` in your web browser. Expect `Media: The Pragmatic Programmer` and `Media: The Matrix` in separate cards. The empty subclasses inherit the constructor and description method.

Temporarily try `new MediaItem(3, 'Generic')` in the entry script. Confirm that PHP rejects instantiating the abstract class, then comment out the line.

## Exercise 3-2: Override and check the intent

In Book, add a public `describe(): string` method marked with `#[Override]`. Return `'Book: ' . $this->title`. Give DVD a marked override returning `'DVD: ' . $this->title`.

Expect the cards to now read:

```text
Book: The Pragmatic Programmer
DVD: The Matrix
```

Temporarily misspell only Book's method as `descrbie()`. Confirm an Override error, then repair it.

## Exercise 3-3: Augment construction and a method

Give Book a private `int $pageCount` property and a constructor taking `(int $id, string $title, int $pageCount)`.

1. Reject `pageCount < 1` by throwing `InvalidArgumentException`.
2. Call `parent::__construct($id, $title)` to initialize shared state.
3. Assign `pageCount` to the child property. Do not mark the constructor with Override.
4. Replace Book's `describe()` body with a return value built from `parent::describe()` plus `' / '`, the page count, and `' pages'`.
5. Update construction in the entry script to `new Book(1, 'The Pragmatic Programmer', 352)`.

Expect:

```text
Media: The Pragmatic Programmer / 352 pages
DVD: The Matrix
```

## Exercise 3-4: Restrict overriding deliberately

1. Make `MediaItem::setId()` final. Leave the property private.
2. Make the entire DVD class final.
3. Call `$book->setId(10)` and print `$book->getId()` in the entry script. Expect `10`: final methods can still be called.
4. Attempt to override `setId(int $id): void` in Book. Confirm the error, then comment the overriding method out.

## Exercise 3-5: Add a new subclass

Create a new class that extends `MediaItem`. Give it a unique property, constructor, and marked override of `describe()`. Add an instance to the entry script and confirm that all three cards display correctly.
