# 2.2 Declaring Classes and Creating Objects

Chapter 18 moves from the OOP vocabulary to PHP syntax. We will declare one class per file, load its declaration, create objects, and interact with them through methods.

## Declare a class

Create `src/Product.php`:

```php
<?php

declare(strict_types=1);

class Product
{
    private string $name = '';
    private float $price = 0.0;

    public function setName(string $name): void
    {
        $this->name = $name;
    }

    public function getName(): string
    {
        return $this->name;
    }
}
```

`name` and `price` are typed properties. `setName()` and `getName()` are typed methods. `$this` means “the current object”—the particular instance that received the method call.

The class name uses StudlyCaps; methods and properties use camelCase. Modern PHP should declare property, parameter, and return types whenever the intended type is known.

## Visibility

| Modifier | Accessible from |
|---|---|
| `public` | any code with access to the object |
| `protected` | the declaring class and its subclasses |
| `private` | the declaring class only |

Prefer private properties until there is a reason to expose more. Public methods form the class's interface with the rest of the application.

## Load the declaration and create an object

Create `public/index.php`:

```php
<?php

declare(strict_types=1);

require_once __DIR__ . '/../src/Product.php';

$hammer = new Product();
$hammer->setName('Hammer');

echo $hammer->getName();
```

`require_once` evaluates the class declaration before we use it. `__DIR__` makes the path relative to the file containing the statement. The `new` expression creates an object and returns its identity; `$hammer` stores that object reference.

## Each object has its own state

```php
$hammer = new Product();
$saw = new Product();

$hammer->setName('Hammer');
$saw->setName('Saw');

echo $hammer->getName(); // Hammer
echo $saw->getName();    // Saw
```

The method code is shared, but each object keeps its own property values. Inside `setName()`, `$this` refers to `$hammer` for the first call and `$saw` for the second.

Add price behavior in the same way:

```php
public function setPrice(float $price): void
{
    $this->price = $price;
}

public function getPrice(): float
{
    return $this->price;
}
```

Calling code uses `$hammer->setPrice(9.99)`. It cannot use `$hammer->price = 9.99` because `price` is private.

## Instructor demonstration

1. Build the two-file example live.
2. Intentionally omit `require_once` and read the “Class not found” error.
3. Intentionally access `$hammer->price` and read the private-property error.
4. Create a second object and trace how `$this` refers to different instances.
5. Have students predict which mistakes are caught by type declarations.
