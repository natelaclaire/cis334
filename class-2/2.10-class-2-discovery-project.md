# 2.10 Class 2 Discovery Project

Your discovery project for this week is to create your own `Member` and `Post` classes for our Campus Connect application. The class files should be placed in `src/Discovery/` named `Member.php` and `Post.php`, respectively. The `public/discovery/index.php` file should be the entry point for your project. Use the `<article></article>` element from the static listing current found in `public/discovery/index.php` to determine how to display your posts. That should be rendered using a method in your `Post` class called `render()`, which returns a string containing the HTML for the post. The `Member` class should have a constructor that accepts a first name and last name as separate strings. The `Post` class should have a constructor that accepts a `Member` object, a string for the post date, and a string for the post body. Use the commented `$posts` array in `public/discovery/index.php` as a reference for the data structure you will use. You can use property hooks or traditional getters and setters for your properties, but you must use one or the other consistently throughout your classes. You may also add additional properties and methods to your classes as you see fit.

Once you have completed your classes, you should be able to uncomment the PHP code in `public/discovery/index.php` and see your posts rendered on the page. You may also add additional posts to the array to test your classes further.

Feel free to be creative with your post content and styling, but make sure to follow the requirements outlined above. The Discovery Projects throughout the semester are an opportunity for you to apply what you have learned in class and showcase your skills in PHP and object-oriented programming.
