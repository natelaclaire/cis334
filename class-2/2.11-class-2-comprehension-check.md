# 2.11 Class 2 Comprehension Check

Choose the best answer for each question. Each question has one correct answer.

## Questions

1. What is an object?
   A. A file that contains only functions  
   B. A specific instance created from a class  
   C. A superclass that cannot be instantiated  
   D. A PHP array with numeric keys

2. Why might a `price` property be private with a public setter?
   A. To prevent the class itself from reading it  
   B. To validate values before changing the state  
   C. To validate values before changing the state  
   D. To avoid declaring a type

3. What does `$this` mean inside an instance method?
   A. The parent class  
   B. The most recently declared class  
   C. The current object receiving the method call  
   D. The PHP entry-point file

4. Which PHP 8.4 feature can validate `$product->price = 9.99` while preserving property syntax?
   A. A namespace alias  
   B. A property `set` hook  
   C. An abstract method  
   D. An array callback

5. Given a `findMember()` method that returns either a `Member` object or `null`, i.e., `findMember(): ?Member`, which expression safely requests a name when the result may be `null`?
   A. `findMember()->getName()`  
   B. `findMember()::getName()`  
   C. `findMember()?->getName()`  
   D. `findMember()&->getName()`

6. What happens in `$copy = clone $original` when `$original` contains a nested mutable object?
   A. Every nested object is automatically deep-cloned  
   B. The constructor runs again for the copy  
   C. The outer object is distinct, but the nested object is shared by default  
   D. `$original` becomes `null`

7. What is the main purpose of `__clone()`?
   A. To run before any object is constructed  
   B. To customize the newly cloned object after its properties are copied  
   C. To convert an object to JSON automatically  
   D. To intercept unknown static methods

8. What is the difference between a getter and a setter?
   A. A getter changes a value; a setter returns a value  
   B. A getter is public; a setter is private  
   C. A getter returns a value; a setter changes a value  
   D. A getter is static; a setter is non-static

9. What is the difference between a property hook and a traditional accessor?
   A. A property hook is static; an accessor is non-static  
   B. A property hook uses method syntax; an accessor uses property syntax  
   C. A property hook uses property syntax; an accessor uses method syntax  
   D. A property hook is public; an accessor is private

10. What is the difference between a virtual property and a stored property?
   A. A virtual property is declared with `virtual`; a stored property is declared with `stored`  
   B. A virtual property is public; a stored property is private  
   C. A virtual property has no backing storage and is computed on the fly; a stored property has backing storage  
   D. A virtual property is static; a stored property is non-static


## Answer key and teaching notes

1. **B.** A class is the blueprint; an object is one instance with its own identity and state.
2. **B.** The setter can enforce an invariant such as a nonnegative price.
3. **C.** `$this` refers to the object that received the current method call.
4. **B.** A PHP 8.4 `set` hook intercepts assignment and can normalize or reject the value.
5. **C.** `?->` returns `null` instead of invoking the method when the value on its left is `null`.
6. **C.** PHP performs a shallow clone; nested object identifiers are copied unless customized.
7. **B.** `__clone()` runs on the copy and can clone nested objects, reset state, or assign a new identity.
8. **C.** A getter returns a value; a setter changes a value.
9. **C.** A property hook uses property syntax; an accessor uses method syntax.
10. **C.** A virtual property has no backing storage and is computed on the fly; a stored property has backing storage.
