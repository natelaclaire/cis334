## Exercise 2-2: Complete the `Player` class with property hooks

Open `src/Exercises/Class2/Player.php`. Inside the class, replace the `TODO: Exercise 2-2` comment with:

```php
private static int $nextId = 1;

public private(set) int $id;

public string $name {
    set {
        $value = trim($value);

        if ($value === '') {
            throw new InvalidArgumentException('The player name cannot be empty.');
        }

        $this->name = $value;
    }
}

public string $gamerTag {
    set {
        $value = trim($value);

        if ($value === '') {
            throw new InvalidArgumentException('The gamer tag cannot be empty.');
        }

        $this->gamerTag = $value;
    }
}

public string $displayName {
    get => "{$this->gamerTag} ({$this->name})";
}

public function __construct(string $name, string $gamerTag)
{
    $this->id = self::$nextId++;
    $this->name = $name;
    $this->gamerTag = $gamerTag;
}

public function __toString(): string
{
    return $this->displayName;
}

public function __clone(): void
{
    $this->id = self::$nextId++;
    $this->gamerTag = $this->gamerTag . '-copy';
}
```

The `name` and `gamerTag` properties are backed properties with `set` hooks. `displayName` is a virtual, get-only property. The ID is publicly readable but can be changed only inside `Player`. The `__clone()` method gives a clone a new ID and gamer tag; the constructor is not called when an object is cloned.

Save the file. Do not change `index.php` yet.
