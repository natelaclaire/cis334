# 2.0 Class 2 Overview and Tutorial Roadmap

Welcome! Class 2 covers Chapters 17 and 18 of *PHP Crash Course*. Chapter 17 gives us the mental model for object-oriented programming (OOP); Chapter 18 turns that model into working PHP classes and objects. We will use PHP 8.4 syntax where it improves the ideas in the book.

By the end of this class, you should be able to:

* distinguish a class from an object;
* identify useful properties, methods, and relationships in a problem domain;
* declare a typed class and create objects from it;
* protect an object's state with visibility, accessors, and validation;
* explain when PHP 8.4 property hooks can replace routine getters and setters;
* initialize objects with constructors and represent them as strings;
* explain object-reference assignment and safely handle a missing object; and
* design a small object-oriented entry point whose objects collaborate.

## Tutorial sequence

1. **2.1 — Thinking in Classes and Objects:** classes, objects, messages, relationships, encapsulation, introductory inheritance, overriding, and OOP flow of control (Chapter 17).
2. **2.2 — Declaring Classes and Creating Objects:** class files, typed properties, methods, visibility, `$this`, `require_once`, `new`, and the object operator (Chapter 18).
3. **2.3 — Encapsulation, Accessors, and Property Hooks:** private state, getters, setters, validation, asymmetric visibility, and PHP 8.4 property hooks (Chapter 18 plus a PHP 8.4 extension).
4. **2.4 — Constructing and Describing Objects:** constructors, constructor property promotion, `__toString()`, custom methods, and virtual/computed attributes (Chapter 18).
5. **2.5 — Object References and Missing Objects:** reference-like object assignment, identity, nullable object types, and the nullsafe operator (Chapter 18 plus modern syntax).

After the tutorials, complete the five reinforcement exercises in 2.6 and the ten-question comprehension check in 2.7.

## Scope note

Chapter 17 briefly introduces inheritance and overriding so that students can recognize those ideas. Their full PHP implementation—including abstract classes, `parent::`, substitutability, and `final`—belongs with Chapter 19 and is taught in Class 4. Namespaces and autoloading likewise remain with Chapter 20.
