# 2.7 Class 2 Comprehension Check

Choose the best answer for each question. Each question has one correct answer.

## Questions

1. What is an object?
   A. A file that contains only functions  
   B. A specific instance created from a class  
   C. A superclass that cannot be instantiated  
   D. A PHP array with numeric keys

2. Which statement best describes encapsulation?
   A. Placing every class in one file  
   B. Copying methods into several classes  
   C. Grouping related state and behavior in a class  
   D. Making every property public

3. In `$post->author->getDisplayName()`, what does `->` do?
   A. Separates an array key from its value  
   B. Declares inheritance  
   C. Accesses a member of an object  
   D. Creates a reference with `&`

4. Why might a `price` property be private with a public setter?
   A. To prevent the class itself from reading it  
   B. To validate values before changing the state  
   C. To make the property static  
   D. To avoid declaring a type

5. What does `$this` mean inside an instance method?
   A. The parent class  
   B. The most recently declared class  
   C. The current object receiving the method call  
   D. The PHP entry-point file

6. Which PHP 8.4 feature can validate `$product->price = 9.99` while preserving property syntax?
   A. A namespace alias  
   B. A property `set` hook  
   C. An abstract method  
   D. An array callback

7. What is a virtual property?
   A. A property declared outside a class  
   B. A static property shared by every object  
   C. A property whose value is computed rather than stored  
   D. A property with no type

8. When does PHP call `__construct()`?
   A. When an object is created with `new`  
   B. Whenever a property is read  
   C. Only when `__toString()` fails  
   D. When a class file is required

9. After `$second = $first;` for an object, which statement is true?
   A. `$second` is always a deep clone  
   B. The two variables identify the same object  
   C. `$first` becomes `null`  
   D. PHP invokes the constructor again

10. Given `findMember(): ?Member`, which expression safely requests a name when the result may be `null`?
    A. `findMember()->getName()`  
    B. `findMember()::getName()`  
    C. `findMember()?->getName()`  
    D. `findMember()&->getName()`

## Answer key and teaching notes

1. **B.** A class is the blueprint; an object is one instance with its own identity and state.
2. **C.** Encapsulation organizes related properties and methods together; visibility supports information hiding.
3. **C.** `->` is the object operator. `=>` is used for array key/value pairs.
4. **B.** The setter can enforce an invariant such as a nonnegative price.
5. **C.** `$this` changes meaning with the receiving object, not with a variable name in the caller.
6. **B.** A PHP 8.4 `set` hook intercepts assignment and can normalize or reject the value.
7. **C.** A virtual property computes its result and has no backing value of its own.
8. **A.** The `new` expression automatically invokes the constructor with the supplied arguments.
9. **B.** Object assignment copies the object identifier; use `clone` when an independent object is required.
10. **C.** `?->` returns `null` instead of invoking the method when the value on its left is `null`.

Suggested scoring: 9–10 ready to continue; 7–8 review the missed tutorial sections; 0–6 revisit the demonstrations before beginning the discovery project.
