# 7.11 Class 7 Discovery Project

Create a form at the bottom of the feed page that allows the user to add a post. The form should have a text input for the post content and a submit button. Consider what validations are appropriate for the post content. For example, you may want to ensure that the content is not empty and does not exceed a certain length, or that it doesn't contain certain words. Create custom exceptions for any validation errors, implement validation logic that throws these exceptions, and handle them appropriately in the controller.

When the form is submitted, if it validates successfully, the new post should be added to the feed and displayed at the top of the list of posts. There is no need to persist the post for now (just display it on the page until the page is reloaded), but in a future implementation, we will need to store the post in a database. The member associated with the post is up to you - in the future we'll add user accounts, but for now you can just use a placeholder name or ID. If the form submission fails validation, display an appropriate error message to the user and re-display the form.

As with all discovery projects, this is an opportunity for you to apply what you have learned in class and showcase your skills in PHP and object-oriented programming. It's also an opportunity for you to explore and discover. Feel free to be creative, as long as you follow the requirements outlined above.
